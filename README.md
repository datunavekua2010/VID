# Axiom Academy: The Second Chance

A 30-second, vertical, frame-animated Remotion film with a playable React preview. The boy, environments, props, portal, and mathematical demonstration are drawn and animated in code; no generated pictures or remote assets are used. The soundtrack and synchronized foley are original, synthesized specifically for the film.

## Preview

Requires Node.js 20 or newer.

```sh
npm ci
npm run dev
```

Open the local Vite address printed in the terminal. The preview has playback, seeking, scene selection, sound, fullscreen, and a download of the rendered film. For Remotion's editing interface instead, run `npm run studio`.

## Render

```sh
npm run render
```

This renders `AxiomAd` as H.264, then trims AAC encoder padding so both streams and the container end at exactly 30 seconds. The result is `public/axiom-second-chance.mp4`. Extra Remotion render flags can be passed after `--`, for example `npm run render -- --concurrency=1`. The first render downloads Remotion's headless Chromium; Linux also needs Chromium's usual system libraries. Remotion includes its own FFmpeg.

To verify the output:

```sh
npx remotion ffprobe -v error -show_entries stream=codec_name,width,height,r_frame_rate,nb_frames,duration:format=duration -of json public/axiom-second-chance.mp4
```

The composition is 1080 x 1920, 30 fps, and exactly 900 frames. The six scene starts are frames 0, 150, 270, 450, 630, and 780. Adjacent scenes overlap for a 14-frame dissolve without extending the timeline.

## Cloud Rendering

The included `.github/workflows/render.yml` can be run with **Actions > Render Axiom Ad > Run workflow**. It installs dependencies, renders the same composition on an Ubuntu runner, and uploads `axiom-second-chance.mp4` as an artifact. No external APIs, secrets, or asset services are required. The same entry point, `src/remotion.ts`, can be bundled by Remotion cloud renderers.

## Project Notes

- `src/video/AdComposition.tsx` contains the six timed Remotion sequences and the sound mix.
- `src/video/scenes/` contains the reusable scene components.
- `src/video/components/Boy.tsx` is the consistent, replaceable character rig. The classroom is shared by the opening and payoff scenes.
- `public/audio/second-chance-original.wav` is generated by `python3 scripts/create-audio.py`. Its final fade and headroom are built into the source mix.
- `public/fonts/` contains local Fraunces, DM Sans, and Noto Sans Georgian font subsets, distributed under the SIL Open Font License.
- No grade outcome is promised; the A is the fictional result in this story.
